# Code of Conduct

Levni follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in every project space: issues, pull requests, discussions and reviews.

In short: be kind and patient, critique the drawing or the code and not the person, assume good faith, and remember that many contributors write in a second language. Harassment, insults, sexualised language or imagery, and publishing someone's private information are not accepted.

## Reporting

Report a problem privately to the maintainers through the contact page at [ortakalan.io/iletisim](https://ortakalan.io/iletisim/) (write "Levni conduct" in the subject). Reports are read by the maintainers only and kept confidential.

Maintainers may edit or remove comments, commits, drawings and issues that break this code, and may warn, suspend or ban a contributor, following the Covenant's enforcement guidelines.
