# Levni brand kit

The files the Levni mark and share cards are made of. Use them for the GitHub organization, social profiles, talks and press.

| file | use |
| --- | --- |
| `levni-avatar.png` / `.svg` | GitHub organization and social avatar (1024 × 1024, indigo ground) |
| `levni-mark-indigo.png` / `.svg` | the mark on light backgrounds |
| `levni-mark-white.png` / `.svg` | the mark on indigo or dark backgrounds |
| `levni-mark-lime.png` / `.svg` | the mark as a lime sticker |
| `levni-github-social-preview.png` | GitHub repository social preview (1280 × 640) |
| `levni-share-card.png` | default Open Graph card (1200 × 630) |

The mark is a chamfered block with a 7 × 9 pixel tulip cut out of it, after the Tulip Era painter Levni.

**Colours:** indigo `#4B2FD6`, deep indigo `#2B1A8F`, lime `#D6E521`, red `#FF3A44`, paper `#F3F1EA`, ink `#1B1340`.
**Type:** Bricolage Grotesque for headlines and text, IBM Plex Mono for labels and code (both on Google Fonts, OFL).
**Voice:** a post-AI center for designers. Plain, a little dry, never hype. See the [manifesto](https://levni.dev/manifesto/).

Share cards are drawn by Levni itself: `node site/scripts/render-og.mjs`.
